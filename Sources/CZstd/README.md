# CZstd — vendored Zstandard **decompressor** (decode-only)

This is a **vendored, decompression-only** build of [Zstandard](https://github.com/facebook/zstd),
wrapped as a SwiftPM C target so `VibeMenuCore` can decode the zstd-compressed body of the Claude
**Desktop** local HTTP cache entry for the usage endpoint (see
[`docs/decisions/0016-claude-usage-limits.md`](../../docs/decisions/0016-claude-usage-limits.md)).

macOS ships **no** zstd: Apple's `Compression` framework does zlib/lzfse/lz4/lzma/brotli only, and
there is no system `libzstd` in the macOS 26 dyld cache. So decoding Claude Desktop's cache requires
a bundled decoder. Per the project rules we do **not** shell out to a `zstd` binary, use Homebrew, or
fetch anything over the network — we vendor the official, audited decoder source instead.

## What is here

| File | Origin |
| --- | --- |
| `zstddeclib.c` | The official **single-file, decompression-only** amalgamation of zstd. |
| `include/zstd.h` | zstd public API header (unmodified, from `lib/zstd.h`). |
| `include/zstd_errors.h` | zstd error codes header (unmodified, from `lib/zstd_errors.h`). |
| `include/module.modulemap` | Exposes the C API to Swift as `import CZstd`. |
| `LICENSE` | zstd's `LICENSE` (BSD-3-Clause). |

## Provenance (reproducible)

- **Upstream:** https://github.com/facebook/zstd
- **Release tag:** `v1.5.6`
- **Commit:** `794ea1b0afca0f020f4e57b6732332231fb23c70`
- **`zstddeclib.c` generated by zstd's own amalgamation script**, unmodified:
  ```sh
  git clone --depth 1 --branch v1.5.6 https://github.com/facebook/zstd.git
  cd zstd/build/single_file_libs
  ./create_single_file_decoder.sh        # runs: python combine.py -r ../../lib -x legacy/zstd_legacy.h -o zstddeclib.c zstddeclib-in.c
  ```
  `zstd.h` / `zstd_errors.h` / `LICENSE` were copied verbatim from the same checkout. None of these
  files are edited by hand — to update, re-run the steps above at a newer tag and replace them.

## Scope / safety

- **Decode only.** The amalgamation contains no compressor — VibeMenu never compresses anything.
- The Swift wrapper (`Zstd.swift` in `VibeMenuCore`) uses only the stable streaming API
  (`ZSTD_createDCtx` / `ZSTD_decompressStream` / `ZSTD_freeDCtx`) and **caps the decompressed output
  size** to defend against a corrupt/hostile frame (decompression bomb). Input is a local file only;
  there is no network path into this code.
